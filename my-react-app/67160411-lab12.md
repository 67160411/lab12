# 📝 คำถามท้ายปฏิบัติการ - เขียนคำตอบ

## คำถาม 1: useState Hook

### 1.1 อธิบายความแตกต่างระหว่าง state ธรรมดากับ useState Hook

ตัวแปรธรรมดาใน React เมื่อค่าถูกเปลี่ยน UI จะไม่อัปเดต เพราะ React ไม่รู้ว่าค่ามีการเปลี่ยนแปลง แต่ `useState` เป็น Hook ที่ใช้เก็บ state ของ component เมื่อใช้ `setState` เพื่อเปลี่ยนค่า React จะทำการ **re-render component** ทำให้ UI อัปเดตตามค่า state ใหม่โดยอัตโนมัติ

### เขียนตัวอย่างโค้ด 2 แบบเพื่อแสดงความแตกต่าง แล้วอธิบายว่าทำไม UI ในแบบ 2 จึงอัปเดตอัตโนมัติ

1. ตัวแปรธรรมดา (ไม่ใช้ useState)

```js
function Counter() {
  let count = 0;

  function increment() {
    count = count + 1;
    console.log(count);
  }

  return (
    <div>
      <p>{count}</p>
      <button onClick={increment}>เพิ่ม</button>
    </div>
  );
}
```

2. ตัวแปร state (ใช้ useState)

```js
import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  function increment() {
    setCount(count + 1);
  }

  return (
    <div>
      <p>{count}</p>
      <button onClick={increment}>เพิ่ม</button>
    </div>
  );
}
```

#### สรุป

- ตัวแปรธรรมดา → ค่าเปลี่ยนแต่ UI ไม่อัปเดต
- useState → เมื่อใช้ setState React จะ re-render component ทำให้ UI อัปเดตอัตโนมัติ

#### ตัวอย่างการใช้งานจริง

- ตัวนับจำนวน (Counter)
- ฟอร์มกรอกข้อมูล
- Todo List
- ระบบ Login

### 1.2 เมื่อต้องการจัดการ state แบบ Object (เช่น user ที่มี name, email, age) ควรเขียนแบบไหน?

เมื่อต้องการเก็บข้อมูลหลายค่า เช่น `name`, `email`, `age` สามารถสร้าง state เป็น **Object** ด้วย `useState` ได้ และเวลาจะอัปเดตค่าหนึ่งค่า ต้องใช้ **spread operator (...)** เพื่อคัดลอกค่าที่เหลือไว้ ไม่ให้หายไป

```js
import { useState } from "react";

function UserInfo() {
  const [user, setUser] = useState({
    name: "",
    email: "",
    age: "",
  });

  function updateName(newName) {
    setUser({
      ...user,
      name: newName,
    });
  }

  return (
    <div>
      <input
        type="text"
        placeholder="กรอกชื่อ"
        onChange={(e) => updateName(e.target.value)}
      />

      <p>ชื่อ: {user.name}</p>
      <p>Email: {user.email}</p>
      <p>อายุ: {user.age}</p>
    </div>
  );
}
```

อธิบาย

- `useState` ใช้สร้าง state เป็น Object เพื่อเก็บข้อมูลหลายค่าในตัวแปรเดียว
- การใช้ `...user` คือ spread operator เพื่อคัดลอกข้อมูลเดิมทั้งหมดของ object
- จากนั้นจึงเปลี่ยนเฉพาะ property ที่ต้องการ เช่น `name`

ถ้าไม่ใช้ `...user` ค่าอื่น เช่น `email` และ `age` จะหายไป เพราะ React จะมองว่าเรา แทนที่ object ใหม่ทั้งก้อน

## คำถาม 2: Event Handling

### 2.1 เขียนรายการ Event ทั่วไปใน React และบอกว่าแต่ละ Event ใช้เมื่อไหร่

| Event      | ใช้เมื่อไหร่                       | ตัวอย่าง                 |
| ---------- | ---------------------------------- | ------------------------ |
| onClick    | ใช้เมื่อผู้ใช้คลิกปุ่มหรือ element | ปุ่มเพิ่มตัวเลข          |
| onChange   | ใช้เมื่อค่าของ input มีการเปลี่ยน  | ช่องกรอกชื่อ             |
| onSubmit   | ใช้เมื่อมีการส่ง form              | ฟอร์ม login              |
| onFocus    | ใช้เมื่อ cursor คลิกเข้าไปใน input | คลิกช่องกรอกข้อมูล       |
| onKeyPress | ใช้เมื่อผู้ใช้กดปุ่มบน keyboard    | กด Enter เพื่อเพิ่ม Todo |

#### 1. onClick

ใช้เมื่อผู้ใช้กดปุ่ม

```js
<button onClick={() => alert("คลิกแล้ว")}>กดปุ่ม</button>
```

#### 2. onChange

ใช้เมื่อค่าของ input เปลี่ยน เช่น การพิมพ์ข้อความ

```js
<input type="text" onChange={(e) => console.log(e.target.value)} />
```

#### 3. onSubmit

ใช้เมื่อมีการส่ง form เช่น กดปุ่ม login

```js
function handleSubmit(e) {
  e.preventDefault();
  console.log("ส่งฟอร์มแล้ว");
}

<form onSubmit={handleSubmit}>
  <button type="submit">Login</button>
</form>;
```

#### 4. onFocus

ใช้เมื่อผู้ใช้คลิกเข้าไปในช่อง input

```js
<input type="text" onFocus={() => console.log("กำลังกรอกข้อมูล")} />
```

#### 5. onKeyPress

ใช้เมื่อผู้ใช้กดปุ่มบน keyboard เช่น Enter

```js
<input
  type="text"
  onKeyPress={(e) => {
    if (e.key === "Enter") {
      console.log("กด Enter");
    }
  }}
/>
```

### 2.2 เมื่อสร้าง Form ใน React ควรใช้ Controlled Component ทำไม?

**Controlled Component** คือ input ที่ค่าถูกควบคุมโดย **state ใน React** แทนที่จะให้ HTML จัดการเอง ทำให้ React สามารถควบคุมข้อมูลในฟอร์มได้ทั้งหมด

เมื่อผู้ใช้พิมพ์ข้อมูล ค่าใน input จะถูกอัปเดตเข้า **state** ผ่าน `onChange` และ input จะอ่านค่าจาก state กลับมาแสดง

#### ตัวอย่างโค้ด Controlled Component

```js
import { useState } from "react";

function LoginForm() {
  const [username, setUsername] = useState("");

  return (
    <div>
      <input
        type="text"
        value={username}
        onChange={(e) => setUsername(e.target.value)}
        placeholder="กรอกชื่อผู้ใช้"
      />

      <p>คุณพิมพ์: {username}</p>
    </div>
  );
}
```

ประโยชน์ของ Controlled Component

- สามารถ ตรวจสอบข้อมูล (validation) ได้ เช่น
- ตรวจสอบว่ากรอกครบหรือไม่
- สามารถ reset form ได้ง่ายโดยการ reset state
- สามารถ จัดการข้อมูลก่อนส่ง form ได้
- ทำให้ React ควบคุมข้อมูลในฟอร์มได้ทั้งหมด

## คำถาม 3: Conditional Rendering

### 3.1 มีวิธี 3 วิธีในการ render ตามเงื่อนไข ให้เขียนตัวอย่างแต่ละวิธี

#### 1. Ternary Operator - แสดง/ซ่อน 2 element

ใช้เมื่อมี **2 เงื่อนไข** เช่น แสดงหรือซ่อน element

```js
function LoginStatus({ isLoggedIn }) {
  return (
    <div>{isLoggedIn ? <p>ยินดีต้อนรับ</p> : <p>กรุณาเข้าสู่ระบบ</p>}</div>
  );
}
```

ใช้เมื่อไหร่

- มีเงื่อนไขแค่ 2 แบบ
- ต้องการเขียนสั้น ๆ ภายใน JSX

ข้อดี

- โค้ดสั้น อ่านง่าย

ข้อเสีย

- ถ้ามีหลายเงื่อนไข โค้ดจะอ่านยาก

#### 2. Logical AND (&&) - แสดง element เมื่อเงื่อนไขเป็น true

ใช้เมื่อ **ต้องการแสดง element เฉพาะตอนเงื่อนไขเป็น true**

```js
function Notification({ hasMessage }) {
  return <div>{hasMessage && <p>📩 คุณมีข้อความใหม่</p>}</div>;
}
```

ใช้เมื่อไหร่

- ต้องการแสดง element เฉพาะตอนเงื่อนไขเป็น true
- ไม่มีกรณี else

ข้อดี

- โค้ดสั้นมาก

ข้อเสีย

- ใช้ไม่ได้ถ้ามี else

#### 3. if/else ภายนอก JSX - ใช้ variable เก็บ element

ใช้เมื่อ **หลายเงื่อนไข หรือ logic ซับซ้อน**

```js
function Status({ status }) {
  let message;

  if (status === "success") {
    message = <p>สำเร็จ</p>;
  } else {
    message = <p>กำลังทำงาน</p>;
  }

  return <div>{message}</div>;
}
```

ใช้เมื่อไหร่

- มีหลายเงื่อนไข
- มี logic ซับซ้อน

ข้อดี

- โค้ดอ่านง่ายเมื่อมีหลายเงื่อนไข

ข้อเสีย

- โค้ดยาวกว่า

### 3.2 เขียน Component ที่แสดงสถานะ Loading, Success, Error

```js
import { useState } from "react";

function StatusExample() {
  const [status, setStatus] = useState("idle");

  let message;

  if (status === "idle") {
    message = <p>กรุณากดปุ่ม</p>;
  } else if (status === "loading") {
    message = <p>⏳ กำลังโหลด...</p>;
  } else if (status === "success") {
    message = <p>สำเร็จ!</p>;
  } else if (status === "error") {
    message = <p>❌ เกิดข้อผิดพลาด</p>;
  }

  return (
    <div>
      <h2>สถานะระบบ</h2>

      {message}

      <button onClick={() => setStatus("loading")}>Loading</button>
      <button onClick={() => setStatus("success")}>Success</button>
      <button onClick={() => setStatus("error")}>Error</button>
      <button onClick={() => setStatus("idle")}>Reset</button>
    </div>
  );
}
```

อธิบาย

- ใช้ `useState` เก็บค่า `status`
- ใช้ conditional rendering เพื่อแสดงข้อความตามสถานะ
- ปุ่มแต่ละปุ่มใช้ `setStatus()` เพื่อเปลี่ยนสถานะ
- เมื่อ state เปลี่ยน React จะ re-render component ทำให้ข้อความเปลี่ยนทันที

## คำถาม 4: Form & State Management

### 4.1 เขียน Component LoginForm ที่มี: Input: username, Input: password, ปุ่ม: ส่งข้อมูล, แสดงข้อความ “เข้าสู่ระบบสำเร็จเป็น [username]” เมื่อส่งเสร็จ

```js
import { useState } from "react";

function LoginForm() {
  const [username, setUsername] = useState("");
  const [password, setPassword] = useState("");
  const [success, setSuccess] = useState(false);

  function handleSubmit(e) {
    e.preventDefault(); // ป้องกันการ refresh หน้า

    if (username && password) {
      setSuccess(true);
    }
  }

  return (
    <div>
      <form onSubmit={handleSubmit}>
        <input
          type="text"
          placeholder="Username"
          value={username}
          onChange={(e) => setUsername(e.target.value)}
        />

        <input
          type="password"
          placeholder="Password"
          value={password}
          onChange={(e) => setPassword(e.target.value)}
        />

        <button type="submit">ส่งข้อมูล</button>
      </form>

      {success && <p>เข้าสู่ระบบสำเร็จเป็น {username}</p>}
    </div>
  );
}
```

### 4.2 เขียน Component ที่มี Checkbox ติดต่อได้: Checkbox: “ต้องการรับข้อมูลข่าวสาร”, แสดงว่า Checkbox เลือก/ไม่เลือก

```js
import { useState } from "react";

function NewsletterCheckbox() {
  const [subscribe, setSubscribe] = useState(false);

  function handleChange(e) {
    setSubscribe(e.target.checked);
  }

  return (
    <div>
      <label>
        <input type="checkbox" checked={subscribe} onChange={handleChange} />
        ต้องการรับข้อมูลข่าวสาร
      </label>

      <p>สถานะ: {subscribe ? "เลือกแล้ว" : "ยังไม่เลือก"}</p>
    </div>
  );
}
```

##### ความแตกต่างของ onChange

Input (text)

- ใช้ event.target.value
- ค่าที่ได้เป็น ข้อความที่พิมพ์

ตัวอย่าง

```js
onChange={(e) => setName(e.target.value)}
```

Checkbox

- ใช้ event.target.checked
- ค่าที่ได้เป็น true หรือ false

ตัวอย่าง

```js
onChange={(e) => setSubscribe(e.target.checked)}
```

## คำถาม 5: Array Operations with State

### 5.1 เขียนฟังก์ชัน 3 ตัวสำหรับจัดการ array state:

```javascript
import { useState } from "react";

const [todos, setTodos] = useState([]);

function addTodo(newTodo) {
  // เพิ่ม todo ใหม่เข้าไป
  setTodos([...todos, newTodo]);
}

function deleteTodo(id) {
  // ลบ todo ที่มี id นั้น
  setTodos(todos.filter((todo) => todo.id !== id));
}

function updateTodo(id, newText) {
  // อัปเดต text ของ todo ที่มี id นั้น
  setTodos(
    todos.map((todo) => (todo.id === id ? { ...todo, text: newText } : todo)),
  );
}
```

### 5.2 เขียน Component ที่มี Todo List พร้อม: Input สำหรับเพิ่ม todo, ปุ่มเพิ่ม, รายการ todo พร้อมปุ่มลบแต่ละรายการ, แสดง “ยังไม่มีรายการ” เมื่อไม่มี todo

```js
import { useState } from "react";

function TodoList() {
  const [todos, setTodos] = useState([]);
  const [input, setInput] = useState("");

  function addTodo() {
    if (input.trim()) {
      const newTodo = {
        id: Date.now(),
        text: input,
      };

      setTodos([...todos, newTodo]);
      setInput("");
    }
  }

  function deleteTodo(id) {
    setTodos(todos.filter((todo) => todo.id !== id));
  }

  return (
    <div>
      <h2>Todo List</h2>

      <input
        type="text"
        value={input}
        onChange={(e) => setInput(e.target.value)}
        placeholder="เพิ่มสิ่งที่ต้องทำ"
      />

      <button onClick={addTodo}>เพิ่ม</button>

      {todos.length === 0 ? (
        <p>ยังไม่มีรายการ</p>
      ) : (
        <ul>
          {todos.map((todo) => (
            <li key={todo.id}>
              {todo.text}
              <button onClick={() => deleteTodo(todo.id)}>ลบ</button>
            </li>
          ))}
        </ul>
      )}
    </div>
  );
}
```
